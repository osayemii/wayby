# wayby

**School:** Aptech

**Bio:** Aptech wayby website rebuild/WordPress embed project built with Vite.

**Description:** Website rebuild/embed project organized by source folders.

## Root folders

| Folder | What it contains |
| --- | --- |
| `public/` | Static assets. |
| `src/` | React/Vite source code. |

Only root folders are listed. Generated caches, package folders, editor settings, and other non-personal folders are omitted.

## Running the code

There is no single entry point for the whole repo; run individual projects from their folders. Check each folder for its own README, `package.json`, `pubspec.yaml`, `pom.xml`, or build files.
